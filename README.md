# MovieWatchlist

MovieWatchlist is a simple web application built for the Engineering Design 2 "Build Software with AI" assignment. It lets users create and manage a personal movie watchlist.

## Features

- User registration
- User login and logout
- Add movies
- View movies
- Edit movies
- Delete movies
- Mark movies as watched
- Store release year, status, rating, and notes
- Each user sees only their own movies

## Technologies

- HTML
- CSS
- JavaScript
- Parse JavaScript SDK
- Back4App
- GitHub
- Netlify

## Database

Back4App provides the backend.

The application uses:
- `_User` for authentication
- `Movie` for watchlist records

Each Movie stores:
- title
- year
- status
- rating
- notes
- user

## Setup

1. Create a Back4App application.
2. Open App Settings > Security & Keys.
3. Copy the Application ID and JavaScript Key.
4. Put those values into `app.js`.
5. Open `index.html` locally or deploy the project to Netlify.
